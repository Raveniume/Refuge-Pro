# 配装定制回归

2026-11-09 续验。禁止进行 RSI 账户变更，尤其是回收/溶解。共享模拟器使用 `adb install -r` 保留会话。

## 发现的缺陷

- `NativeLoadoutScreen` 仅绘制性能与电力面板，`picker` 只能选择舰船；组件选择和详情成为不可达代码。
- 旧测试只检查仪表盘、切换和电力，没有执行组件更换，因此不能证明改船可用。
- 旧文档把用户报告“进出没有动画”误写为“要求无动画”。
- Damage 仍用三条细线重绘，未使用已有 Erkul 图形；详情仍绘制返回控件。
- 任务 manifest 未持久化；改船内存缓存丢失后先等网络；蓝图换详情时可能短暂显示上一条内容。
- 改船刷新图标错误绑定清空草稿；改为版本检查，恢复原厂移到菜单并单独确认。
- 任务和蓝图刷新没有结果反馈；手动刷新现显示检查结果，自动检查保持静默。
- 用户指定深蓝底 RSI 图标，使用官方矢量原稿，不再使用火箭图标。

## 实现与验收门槛

- 默认打开配装定制，另有性能数据；按独立挂点展示挂架、子武器、弹药、护盾、发电机、两个散热器、航行和其他设备。
- 兼容组件来自同一 LIVE 版本；更换、卸下、恢复原厂、启停只改本地草稿；验证退出重入后的持久化。
- 两个同型号散热器不得按名字去重；固定挂点标注固定，不伪装为可编辑。
- 更多菜单必须实际打开性能、保存、调用和设置；只有文字或存在语义节点不算通过。
- 有缓存先显示缓存，版本检查在后台进行；首次无缓存可显示紧凑加载状态，不能编造数据。
- 检查根路由、设置、定制、组件、任务和蓝图的深浅色、返回与进出过渡。

## 当前结果

本轮全套 instrumentation 报告 `OK (46 tests)`，明细为 **45 通过、1 条件跳过、0 失败**。跳过项是旧的 M80/Perseus 专属英雄卡测试：当前真实机库不含它指定的条目；不能算已验证。其余真实根页面、深浅色、导航拖动、搜索保留和设置持久化测试均实际执行。单元测试96通过。最后的增量测试10项中9项通过，1项配装测试在导出未合并语义树时出现 SnapshotStateObserver 跨线程竞争。改为系统截图，保留功能断言并增加“对比原厂”开关实际操作；随后配装与真实主入口2项复验全部通过（35.591秒）。截图采集失败没有被当作通过。

最终构建：`testDebugUnitTest`、`lintDebug`、`assembleDebug`、`assembleDebugAndroidTest`、`assembleReview` 成功。Lint无错误，仍有129项警告和2项提示，不宣称零警告。v0.3.14 / versionCode26 的 review APK 已由 `scripts/android.ps1 -Action Install` 覆盖安装成功，真实登录保留；另通过 ADB 点击设置双层玻璃、返回“我的”、进入终端改船和点击刷新，配装页实际出现更换操作。末次“我的”内存快照 TOTAL PSS约162MiB，不能等同全机型性能基准。

已通过真实 LIVE 配装测试：更换武器、刷新后保留替换件、重新进入、卸下/恢复/启停、两个独立散热器、保存/调用方案、配装设置和性能菜单。测试结束恢复原草稿并删除测试方案。公开来源为 Erkul `4.10.2-LIVE.12913470`、SCMDB `4.10.2-live.12913470`、SCM `4.10.2`。

真实入口测试曾发现两类实际问题，已修复并重跑通过：重复预载 LIVE/PTU/任务解析树导致192MB堆内存耗尽；覆盖在详情下的底部导航仍暴露可点击语义。现在只序列预载 LIVE 和知识库，复用解析快照，PTU按需载入；被遮挡导航清除交互语义。

UI 来源核查及适配见 `LIQUID_GLASS_SOURCES.md`。新增设备用例覆盖开关纵向不误触、横向切换、无障碍动作、双层搜索输入/清除、面板短拖回弹和长拖关闭；真实设置页切换双层材质并检查持久化。
