# Asset sources

## Launcher mark (2026-11-09)

User requested a deep navy background and the RSI mark shown in their reference.
The Android vector retains the paths and silver/orange colors of RSI's public
`robertsspaceindustries_multicolor_simplified-1200d799.svg`, with only a uniform
scale and translation into the adaptive-icon safe zone. Background: `#102439`.

Source: https://cdn.robertsspaceindustries.com/orion-v3/logotypes/robertsspaceindustries_multicolor_simplified-1200d799.svg

RSI / Roberts Space Industries is the source brand; this does not change the
application's RefugeNext name or make it an official RSI application.

## Erkul equipment glyphs

Added the public website's original `icons/power/missiles.png`, `mounts.png`,
and `bombs.png` from https://www.erkul.games/. They supplement the existing
weapons/shields/coolers/radar/power assets. Use the component's actual type for
the icon; do not reuse the gun glyph for missiles, or quantum for flight blades.
Source silhouettes are retained; Compose applies the Refuge semantic tint.
